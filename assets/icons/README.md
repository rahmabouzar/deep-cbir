# Icônes personnalisées (optionnel)

Par défaut l'application utilise les icônes **Phosphor** (licence MIT) du dossier `assets/phosphor/`, conformes à SKILL.md.
Un fichier du même nom placé ici les remplace.


Déposez ici des fichiers **SVG** exportés depuis Streamline (set *Flex Pop*, licence à vérifier : le set complet est « Premium »,
une version *Flex Pop – Free* existe sur le site). Chaque fichier doit porter l'un des noms ci-dessous ; s'il est absent,
l'application affiche une icône simple de secours, donc rien ne casse.

| Nom du fichier        | Où il est utilisé                         | Suggestion Flex Pop (nom Streamline)      |
|-----------------------|-------------------------------------------|-------------------------------------------|
| `home.svg`            | Accueil                                   | (à choisir)                               |
| `experience.svg`      | Expérience sur échantillon                | magic-wand-tip-diagonal / pattern         |
| `search.svg`          | Recherche d'images, logo                  | binoculars                                |
| `bars.svg`            | Résultats globaux, cartes de statistiques | (à choisir)                               |
| `curve.svg`           | Courbes Précision-Rappel                  | curves-levels-graph                       |
| `grid.svg`            | Comparaison par classe                    | gallery-view / grid-dots                  |
| `matrix.svg`          | Matrices de confusion                     | grid-dots                                 |
| `compare.svg`         | Comparaisons croisées                     | compare-arrow / compare-ab                |
| `database.svg`        | Bases de données                          | (à choisir)                               |
| `layers.svg`          | Modèles                                   | (à choisir)                               |
| `target.svg`          | Icône par défaut                          | (à choisir)                               |
| `image.svg`           | Images / échantillon                      | edit-compare-image                        |

Les icônes colorées Flex Pop gardent leurs couleurs d'origine. Les boutons, la navigation et les alertes de Streamlit
n'acceptent que des icônes Material : elles restent donc monochromes.

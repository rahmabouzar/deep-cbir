Bases de données et types de fichiers

Chaque base est parcourue récursivement ; la classe est le nom du dossier (Corel, CIFAR) ou lue dans le nom du fichier paris_<classe>_NNNNNN.jpg (Paris). Les images illisibles sont ignorées. Les statistiques ci-dessous sont mesurées sur les fichiers réels.

Base historique : 10 catégories (africains, plages, bâtiments, bus, dinosaures, éléphants, fleurs, nourriture, chevaux, montagnes), 100 images chacune. Classes visuellement très distinctes → base « facile ».
